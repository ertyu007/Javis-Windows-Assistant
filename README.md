# Javis Windows Assistant

Javis Windows Assistant เป็นผู้ช่วย AI ภาษาไทยสำหรับ Windows ที่ช่วยให้คุณสั่งงานเปิดโปรแกรม เว็บไซต์ ไฟล์ และโฟลเดอร์ รวมถึงควบคุมหน้าต่าง กดปุ่ม และพิมพ์คำสั่งต่าง ๆ ได้อย่างรวดเร็วและสะดวก โดยใช้คำสั่งภาษาไทยเป็นหลัก

## ติดตั้ง

1. เปิด `setup.bat`
2. คัดลอก Groq API key ใส่ `GROQ_API_KEY` ใน `.env` หรือเปิด Ollama
3. เปิด `run.bat`

## ตัวอย่าง

- เปิด Chrome
- เปิด YouTube
- ค้นหา Python tutorial
- เปิดโฟลเดอร์ดาวน์โหลด
- เปิดไฟล์ report.pdf
- เล่นเพลง lofi
- ปิดหน้าต่าง Chrome
- พิมพ์ สวัสดีครับ
- กด ctrl+s
- ลดเสียง
- ล็อกหน้าจอ

คำสั่งปิดเครื่อง รีสตาร์ท และพักเครื่องต้องยืนยันก่อนเสมอ

## Skills

ระบบโหลดคำแนะนำจาก `skills/**/SKILL.md` เข้า prompt อัตโนมัติ สามารถเพิ่มโฟลเดอร์ skill ใหม่ได้เอง
